# Herói das Chamas — Mini Jogo de Navegação em HTML

O **Herói das Chamas** é um jogo de aventura em texto (*text adventure*) desenvolvido exclusivamente em **HTML puro**, sem a utilização de CSS, JavaScript ou linguagens de backend. .

---

## Objetivo do Jogo

Você assume o papel de um bombeiro em uma missão de resgate em uma casa pegando fogo. Seu objetivo é navegar estrategicamente pelos cômodos através dos links de navegação até encontrar a vítima no cômodo correto e concluir o resgate com sucesso.
---

## Como Executar o Projeto

1. Baixe ou clone este repositório para o seu computador.
2. Localize o arquivo `index.html`.
3. Dê um duplo clique no arquivo para abri-lo diretamente em qualquer navegador web (Google Chrome, Firefox, Edge, Safari, etc.).
4. **Não é necessário instalar nenhuma dependência ou servidor local!**
